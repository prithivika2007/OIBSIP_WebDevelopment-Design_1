# Brewed Bliss Cafe - Landing Page ☕✨

A responsive, visually engaging landing page designed for a premium cafe called **Brewed Bliss**. This project was developed as part of the **Web Development & Designing Internship** at **Oasis Infobyte** (Task 1).

---

## 📌 Project Objective
The main goal of this project was to design and implement a clean, attractive, and highly interactive landing page for a fictional cafe. The webpage focuses on a user-friendly layout to effectively showcase the cafe's identity, menu offerings, location, and contact information, ensuring a seamless user experience across different devices.

---

## 🛠️ Tools & Technologies Used
* **HTML5:** Used for semantic structuring of the page elements (navigation, sections, menu layout).
* **CSS3:** Used for custom styling, including grid layouts, card designs, color typography, and hover effects.
* **Google Fonts:** Integrated modern typography to match the cozy, warm cafe aesthetic.
* **Font Awesome / Icons:** Added descriptive iconography for a polished visual identity.

---

## 📋 Key Features & Design Layout
The landing page is designed with a sleek dark-themed aesthetic complemented by rich coffee tones (`#EED971` accent color). It features the following sections:

1. **Header & Navigation:** A sticky navigation bar featuring the **Brewed Bliss** logo and smooth navigation links (`About`, `Menu`, `Contact`).
2. **Hero Section:** A captivating background showcasing a signature coffee layout with a prominent tagline: *"Where Every Sip Tells a Story"* and a clear **"Explore Our Menu"** Call-To-Action (CTA) button.
3. **About Us:** A minimalist and clean introductory section describing the cafe's philosophy and commitment to local, ethically-sourced brewing.
4. **Interactive Menu Grid:** A responsive card-based layout showcasing 8 cafe favorites (including Espresso, Matcha Latte, Belgian Waffle, and Classic Cheesecake) complete with descriptions, icons, and precise pricing.
5. **Visit Us & Contact:** A beautifully centered footer block displaying the structural contact information (Address, Phone Number, Operating Hours), complete with active social icons and a copyright attribution.

---

## 🚀 Steps Performed
1. **Wireframing & Structural Design:** Planned the single-page application structure prioritizing readability and natural scrolling hierarchy.
2. **Semantic Implementation:** Coded the landing page using HTML5 structural blocks (`<nav>`, `<header>`, `<section>`, `<footer>`) to maintain a clean codebase.
3. **Styling & Visual Design:** Styled the background imagery, typography, buttons, and custom layout containers via custom CSS files.
4. **Component Alignment:** Built a flexbox/grid wrapper for the menu card elements to maintain uniformity across all listed items.
5. **Testing & Fine-Tuning:** Validated the text elements, scroll anchors, and visual contrast to ensure complete readability.

---

## 🎯 Project Outcome
The final result is a beautiful, modern, and production-ready landing page that establishes a strong visual presence for **Brewed Bliss Cafe**. It effectively implements clean interface principles, clear call-to-actions, and interactive card designs to drive user engagement.
